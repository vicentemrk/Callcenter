CAMBIOS REALIZADOS - CALLCENTERGAMER MARVEL
Fecha: 18-11-2026

1. Diseño y nombre
------------------
- La aplicación usa una combinación de negro y rojo inspirada en Marvel.
- Incluye modo claro y modo oscuro.
- Se cambió el nombre visible de MarvelCallCenter a CallCenterGamer.
- El header, el footer y la navegación muestran la identidad actual.
- Las pantallas se adaptan a visitantes, clientes, técnicos y administradores.

2. Páginas principales
----------------------
- "/" es la página principal de CallCenterGamer.
- "/marvel/" es la página del Universo Marvel.
- "/marvel/catalogo/" muestra el catálogo.
- Cada película o serie tiene una página de detalle.

3. Catálogo Marvel
------------------
- Contiene 75 películas y 56 series.
- Permite buscar títulos y filtrar por tipo y fase.
- Los personajes ya no forman parte del catálogo.
- Los datos se sincronizan desde MCU API, pero las páginas usan la base local.
- Se agregó una imagen de respaldo para "Untitled X-Men film".

4. Imágenes
-----------
- La landing principal usa un póster de WandaVision.
- La landing principal incluye un carrusel con Avengers: Endgame,
  Avengers: Infinity War, Spider-Man: Homecoming, Thor: Love and Thunder,
  Avengers: Doomsday e Iron Man.
- La landing Marvel usa pósteres de Iron Man, Capitán América, Thor, Hulk,
  Scarlet Witch y Loki.
- Las imágenes se guardan dentro del proyecto para que carguen sin depender
  de una conexión externa.

5. Consultas y categorías
-------------------------
- Las consultas ya no son sobre hardware.
- Las categorías son: videojuegos, merchandising, películas, series,
  cómics, figuras y juguetes, eventos, cuenta, pagos y otros.
- Las consultas pueden quedar vinculadas a una película o serie.

6. Reseñas
----------
- Los clientes pueden calificar películas y series.
- La calificación es de 1 a 5 estrellas.
- Cada reseña incluye una referencia temática obligatoria.
- Un usuario puede publicar solo una reseña por título.
- Los administradores pueden ocultar o restaurar reseñas.

7. Técnicos y tickets
---------------------
- Los administradores pueden asignar o quitar técnicos de un ticket.
- Los técnicos pueden asignarse sus propios tickets.
- Los tickets cerrados no permiten cambios hasta ser reabiertos.
- El panel muestra quién atiende cada consulta.

8. Asistente virtual
--------------------
- Responde y clasifica consultas con contexto Marvel.
- Diferencia entre videojuegos Marvel y problemas técnicos.
- Conserva respuestas de respaldo si el servicio externo falla.

9. Datos de demostración
------------------------
- Se cargaron datos directamente en db.sqlite3.
- Hay 6 usuarios demo: 1 administrador, 2 técnicos y 3 clientes.
- Hay 15 tickets, 17 respuestas y 12 reseñas demo.
- Las cuentas demo usan la contraseña temporal 1234.

10. Validación
--------------
- Las migraciones fueron revisadas.
- Las páginas principales responden correctamente.
- El login fue probado para cliente, técnico y administrador.
- Las pruebas existentes se adaptaron a la identidad Marvel y a las nuevas
  funciones.

ARCHIVOS PRINCIPALES
--------------------
- online/templates/index.html: landing principal.
- marvel/templates/marvel/universo.html: landing Universo Marvel.
- marvel/templates/marvel/catalogo.html: catálogo.
- marvel/templates/marvel/detalle.html: ficha de una película o serie.
- online/templates/componentes/header.html: header y footer.
- marvel/views.py: navegación y reseñas.
- marvel/models.py: películas, series y reseñas.
- administracion/servicios/tickets.py: asignación de técnicos.

GUÍA SIMPLE DEL PROGRAMA
------------------------

1. Punto de entrada
   CallCenterGamer/urls.py recibe las direcciones web. Por ejemplo, "/" abre
   la landing principal y "/marvel/catalogo/" abre el catálogo.

2. Usuarios y sesiones
   online/models.py define usuarios, clientes, técnicos y administradores.
   online/views.py controla registro, inicio de sesión, cierre de sesión,
   tickets del cliente y respuestas.
   online/forms.py valida los datos que se escriben en estos formularios.

3. Catálogo Marvel
   marvel/models.py guarda películas, series e imágenes.
   marvel/views.py muestra el catálogo, las fichas y las reseñas.
   marvel/urls.py define las rutas /marvel/, /marvel/catalogo/ y detalle.
   marvel/services.py convierte los datos recibidos desde MCU API para guardar
   solo películas y series.
   marvel/mcu_client.py se comunica con MCU API. La navegación normalmente
   lee la base local y no necesita llamar a Internet.

4. Landing principal
   online/templates/index.html define la página "/" y el carrusel.
   online/views.py prepara las películas que aparecen en el carrusel.
   online/static/landing.css controla el diseño y responsive del carrusel.
   online/static/img/marvel/ guarda los pósteres locales.

5. Landing Universo Marvel
   marvel/templates/marvel/universo.html muestra el universo Marvel.
   marvel/static/universo.css define su diseño.
   Esta página muestra títulos destacados desde la base local.

6. Tickets y atención
   online/models.py guarda preguntas y respuestas.
   administracion/views.py recibe las acciones del panel administrativo.
   administracion/servicios/tickets.py modifica, cierra, reabre y elimina
   tickets.
   administracion/servicios/panel.py prepara las estadísticas y listas.

7. Roles del sistema
   El cliente crea y sigue sus consultas.
   El técnico responde y puede asignarse tickets.
   El administrador gestiona usuarios, tickets y reseñas.

8. Reseñas
   marvel/forms.py valida la calificación y la referencia temática.
   marvel/models.py guarda una sola reseña por cliente y título.
   marvel/views.py decide qué reseñas puede ver cada rol.

9. Asistente virtual
   online/ia_utils.py genera respuestas y clasifica categorías.
   online/recomendaciones_ia.py ofrece respuestas similares.
   online/constants.py reúne las categorías disponibles.

10. Plantillas visuales
    online/templates/componentes/header.html contiene el menú y el footer.
    online/templates/inicio.html es el panel del cliente.
    online/templates/Respuestas.html muestra conversación y respuestas.
    administracion/templates/ contiene las páginas de administración.

11. Base de datos
    db.sqlite3 contiene usuarios, tickets, respuestas, películas, series
    y reseñas. Es el archivo principal que conserva los datos de la demo.
